# Playlist Music Bot — Stage 2
- آرشیو پست‌های صوتی `ARCHIVE_CHANNEL`
- کپشن: خط اول عنوان، خط دوم خواننده، خط سوم توضیح
- نادیده گرفتن تگ‌هایی مثل `@Playlistmusicbox`
- رد کردن Demo / Preview / Teaser / دمو / پیش‌نمایش / تیزر
- تشخیص فایل تکراری با Telegram file_unique_id
- جلوگیری از تکرار عنوان+خواننده برای Original
- جستجو با `/search`
- ارسال فایل آرشیوشده
Variables: BOT_TOKEN, ADMIN_ID, ARCHIVE_CHANNEL
پیام‌های قدیمی کانال خودکار بازخوانی نمی‌شوند؛ برای تست یک پست صوتی جدید بگذارید.


# Playlist Music Bot — Stage 1

این نسخه فقط «پایه ۱» پروژه است:
- هسته ربات
- دیتابیس SQLite
- کاربران
- خواننده‌ها
- آلبوم‌ها
- آهنگ‌ها
- فالو
- لایک
- پلی‌لیست
- تاریخچه
- جستجوها
- اعلان‌ها
- گزارش‌ها
- کانال‌های اجباری
- تبلیغات
- لاگ مدیر

## Railway Variables

این دو مقدار را در Railway Variables قرار بده:

BOT_TOKEN=توکن ربات
ADMIN_ID=509506756

توکن را داخل چت یا GitHub قرار نده.

## اجرا

pip install -r requirements.txt
python bot.py

## تست Stage 1

1. ربات را اجرا کن.
2. /start را بزن.
3. دکمه‌های منو را تست کن.
4. با اکانت ادمین /admin را بزن.
5. باید آمار دیتابیس را ببینی.

بعد از تأیید این مرحله، Stage 2 را می‌سازیم:
آرشیو واقعی آهنگ از کانال + تشخیص دمو + فایل کامل + جلوگیری از تکراری‌ها + اتصال جستجو به فایل‌های آرشیوشده.
